# Connect the Contact Us form to Zoho CRM

The site saves each Contact Us inquiry in MongoDB, then sends a copy to Zoho CRM Leads from the server. Customer submissions still succeed if Zoho is unavailable. The admin lead detail shows **Zoho CRM** as Synced, Already in CRM, Not configured, or Failed. Existing leads are not changed by this integration.

1. Sign in to the [Zoho API Console](https://api-console.zoho.com/) for the same Zoho CRM organization that should receive leads. Create a **Self Client**. Generate a one-time grant token with the scope `ZohoCRM.modules.leads.CREATE`, then exchange it for a refresh token using the [Zoho self-client OAuth instructions](https://www.zoho.com/crm/developer/docs/api/v8/auth-request.html). Use the Zoho Accounts domain for your account's data center. A one-hour access token is not sufficient; the site needs the refresh token.
2. In the Vercel project's **Settings → Environment Variables**, add `ZOHO_REGION`, `ZOHO_CLIENT_ID`, `ZOHO_CLIENT_SECRET`, and `ZOHO_REFRESH_TOKEN` for Production. Set `ZOHO_REGION` to your account domain suffix: `com` (US), `in` (India), `eu` (Europe), `com.au`, `jp`, `com.cn`, `ca`, or `sa`. Keep all four values server-only; do not prefix them with `NEXT_PUBLIC_`, paste them into the contact form, or commit them to GitHub. If using a preview deployment, add them to Preview separately.
3. Redeploy after adding the variables. Submit one Contact Us inquiry using a new address you control. Open `/admin/leads` and check its **Zoho CRM** status, then check Zoho CRM → Leads for the record. If Zoho marks it Already in CRM, the email or another unique field matched an existing lead and the site did not overwrite that record.

The integration sends name, email, phone, company, and the requested service and message in the Zoho Lead description. Campaign UTM values and the website lead ID are also included there. Only Contact Us submissions are synced. The Zoho CRM field metadata for this organization shows that `Last_Name` is the required field and `Lead_Source` does not have a Website option, so the integration leaves that picklist unset.

Zoho API references: [refresh tokens](https://www.zoho.com/crm/developer/docs/api/v8/refresh.html), [insert Leads](https://www.zoho.com/crm/developer/docs/api/v8/insert-records.html), and [data center domains](https://www.zoho.com/crm/developer/docs/api/v8/multi-dc.html).
