# Optimized Texas SEO SOP

Last Updated: 2026-07-30

Companion document: [Texas Local SEO Page Cluster Roadmap](./TEXAS_LOCAL_SEO_PAGE_CLUSTER_ROADMAP.md)

## Purpose

This file is the working SOP for planning, building, publishing, and tracking Texas city and service pages for IntegraFin.

Use it to keep the work organized, avoid duplicate pages, and make sure every page has a clear search intent and a real service purpose.

## Core Rules

1. One primary keyword per page.
2. One page = one main intent.
3. Do not copy city pages and only swap the city name.
4. Do not use `CPA` in titles or keywords unless the firm or professional is properly licensed to use it.
5. Only use Indian-American or US-India tax language if the firm genuinely has qualified expertise in that work.
6. Never claim a local office in a city where IntegraFin does not actually have one.
7. Every page should include:
   - A clear title and meta description
   - One H1
   - Real service details
   - Local context
   - FAQ content
   - Internal links
   - Schema where relevant
   - Sitemap inclusion

## Page Build Checklist

Before a page is marked done:

1. Confirm the page has a single primary keyword.
2. Make the copy unique to the city and service.
3. Include honest service-area language.
4. Add FAQs that match the page topic.
5. Add internal links to the most relevant service and city pages.
6. Include schema if the page type supports it.
7. Add the page to the sitemap.
8. Add the page to the city or service hub.
9. Request indexing after deploy.
10. Record the result in this file.

## Page Writing Pattern

Each page should usually include:

1. A direct answer near the top.
2. A service description.
3. Who the page helps.
4. Common local scenarios.
5. Why IntegraFin is a fit.
6. FAQ content.
7. Internal links to related pages.
8. A clear CTA.
